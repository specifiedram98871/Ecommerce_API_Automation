# Selenium Automation Framework

This project is a **Selenium + TestNG + Maven framework** for web automation, demonstrating an **E2E Login Test**.

## Prerequisites

- **Java JDK 8 or higher**
- **Maven**
- **IDE** (IntelliJ, Eclipse, VS Code)
- **Chrome browser** (WebDriverManager handles driver)

---

## Install JDK

1. Download JDK from [Oracle](https://www.oracle.com/java/technologies/javase-downloads.html) or [OpenJDK](https://openjdk.org/).  
2. Set `JAVA_HOME` and add to `PATH`.  
3. Verify:

```bash
java -version
javac -version  bash 
```

## Install Maven

1. Install Maven
2. Download Maven from `https://maven.apache.org/`. Apache Maven
3. Set `MAVEN_HOME` and add to `PATH`.

Verify:

```bash
mvn -version
```
## Clone the repository

```bash
git clone https://github.com/specifiedram98871/Ecommerce_API_Automation.git
cd Ecommerce_API_Automation
```

##  Build the project

```bash
mvn clean install
```

## Run the tests

```bash
mvn test
```
